Define an AOI and species list.

Run dataprep/pullgbif to grab non-avian species.

Download ebird species of interest.  Per-species downloads live under /mnt/f/biodiversity/ebird as
  ebd_<pkg>/ebd_<pkg>.txt  (tab-delimited observation files).

Convert downloads to hive parquet for geeDataFromPoints (from WSL terminal, not a notebook cell):
  conda activate rapids-25.10
  cd dataprep && python -u convert_ebird_downloads.py 2>&1 | tee /mnt/f/biodiversity/logs/ebird_downloads_to_parquet.log
Output default: /mnt/f/biodiversity/ebirdpolars/scientific_name=<species>/*.parquet
See dataprep/ebirdtoparquet.ipynb for --dry-run, progress checks, and optional national-file workflow.

Optional: partition one national EBD file (~440GB) with partition_ebird.py (EBIRD_INPUT / EBIRD_OUTPUT).

Optional: MAV species list → hive parquet (MAV AOI):
